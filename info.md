## Dépendances

django: Framework web Python haut niveau utilisé pour construire rapidement des applications web robustes et sécurisées.  
Il fournit.

djangorestframework: Extension de Django permettant de créer des API REST facilement.  

psycopg[binary]: Driver PostgreSQL pour Python. Il permet à Django de communiquer avec une base de données PostgreSQL.
La version `[binary]` inclut automatiquement les binaires précompilés pour éviter de compiler manuellement certaines dépendances système.

python-decouple: Bibliothèque utilisée pour séparer la configuration du code source.  

django-cors-headers: Package permettant de gérer les politiques CORS (Cross-Origin Resource Sharing).

drf-spectacular: Outil de génération automatique de documentation OpenAPI/Swagger pour Django REST Framework.
